# Artwork Archive - DISONANCIAS

## Concepts Folder

Generated artwork concepts for individual tracks. These were conceptually designed based on ARTWORK_STRATEGY.md but are not used in the final release (which uses a single album cover).

### Included

- **02_KICKING_STONES.png**: Movimento congelado / ruptura (grey + red palette)
- **03_RESCUE_US.png**: Estructura frágil / vulnerabilidad (blue-grey palette)
- **04_MEDIO_LIMON.png**: Limón + vallenato elements (yellow-terracota palette)
- **05_SIN_TITULO.png**: Comunidad / manos en círculo (warm ochre palette)

These were generated with Python PIL as conceptual mockups. A professional designer could use these as reference or refine them for future use (e.g., individual single releases, merchandise, etc.).

## Why Archived

DISONANCIAS uses a single album cover (zapatillas + reloj photograph from Kicking Stones v2) for all tracks, following industry standard practice (2026). Individual track artwork is rarely used unless tracks are released as independent singles.

## Future Use

- Reference for visual identity if tracks are released individually
- Design inspiration for other projects
- Conceptual foundation if expanding DISONANCIAS visually
