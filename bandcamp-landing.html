DISONANCIAS examines four types of lies: political, personal, inherited, and collective.

This album reads as a single song with macro-structure: Verse → Bridge → Verse → Chorus. Each track investigates cognitive dissonance at a different scale, unified by methodology (code-generated backing tracks), transparent process, and minimal sonic palette.

About This Album

Why This Is An Album

Not by theme alone (each track examines lies at different scales). Coherence through:

  • Methodology: Code-generated backing tracks (custom Python generator per track)
  • Form: Album structure as macro-composition (V→B→V→C)
  • Sonic palette: Minimal synthesis, declamatory vocals, intentional silence
  • Transparency: Visible process, documented, reproducible

Technical Notes

Backing tracks generated with librosa, music21, and NumPy. Vocals delivered in declamatory mode (parlato) rather than traditional singing. No VST presets—simple oscillators only. Complete technical documentation available on GitHub.

About MIRROR CRY

Composer and artist from San Borja, Santiago. Uses code as a compositional tool.

  • 100% code-generated backing tracks
  • AI-assisted (Claude for refactoring + lyrical development)
  • All creative decisions: human-made
  • Vocals: declamatory (parlato, not sung)
  • Process: transparent and documented

Interested in the technical process? Full project documentation, source code, and compositional notes available on GitHub.
