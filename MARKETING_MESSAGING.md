# Mensajería de Marketing: Cómo Hablar Sobre Este Álbum

## El Desafío

Las palabras típicas de marketing indie no funcionan para este álbum:

- ❌ "Crudo y auténtico" (no es crudo; es muy producido)
- ❌ "Producido en bedroom" (no es bedroom; es algoritmo)
- ❌ "Guitarra acústica y verdades universales" (ni una cosa ni la otra)
- ❌ "Generado por IA" (es incorrecto; el IA es una herramienta, no el artista)

Se necesita lenguaje que sea **honesto, técnico, pero accesible**.

## Mensajes Claves por Audiencia

### Para Gente Que No Sabe Nada de Música (Social Media General)

**Headline**: 
"Un álbum sobre las mentiras que vivimos (políticas, personales, heredadas) hecho con código como instrumento. Voz declamada, pensamiento en voz alta."

**Why it works**:
- "Mentiras" es concreto y relatable
- No presupone conocimiento técnico
- El "código" explica *cómo*, "mentiras" explica *por qué*

**Ejemplo de post**:
```
"VOID CHILD. Nuevo proyecto musical.

Cuatro canciones sobre mentiras:
- Kicking Stones: mentira política
- Rescue Us: mentira personal (disonancia cognitiva)
- Medio Limón: mentira heredada (tradición)
- Sin título: admisión colectiva

Backing tracks escritos en código. Voz declamada (no cantada).
Todo hecho honestamente, documentado, transparente.

No es AI-generated. Es AI-assisted composition.
Big difference."
```

### Para Productores/Músicos (Discord, Reddit r/musicproduction)

**Headline**: 
"Four-track concept album about cognitive dissonance/lies we live. 100% custom Python generators (librosa, music21, NumPy). Code-as-composition, not production shortcut."

**Key points**:
- **Not AI-generated**: Artist wrote custom Python tools for each track. Different from commercial AI music tools.
- **AI-assisted**: Used Claude for lyrics improvement and code refinement. But all creative decisions are human-made.
- Herramientas: librosa, music21, NumPy, custom synthesis
- Disponibilidad: "Código documentado en GitHub (parcialmente abierto, no fully open-source)"
- Especificidad: "Cada track tiene su generador custom. Reconstructed from analysis, no reutilización de síntesis."

**Ejemplo de mensaje largo**:
```
The backing tracks are composed, not produced.

- Kicking Stones: syncopated hip-hop rhythm, stochastic variations
- Rescue Us: ambient loops, sine-wave modulation, no harmonic resolution
- Medio Limón: vallenato pattern reconstructed from traditional recordings, then synthesized algorithmically
- Sin título: "Ho Hey"-style stomp-clap, humanized timing but deterministic structure

**About AI**: Used Claude to help refactor code and polish lyrics. But all compositional decisions are artist-made. This is NOT Jukebox or MuseNet output. Think "using a tool" not "AI generated this."

Code will be documented (GitHub, partially public for others to learn/remix).
```

### Para Periodistas/Prensa

**Ángulo 1 - Técnica Honesta (Code-as-Composition)**:
"VOID CHILD uses code as a compositional tool, not production shortcut. 
Each backing track is written in custom Python (librosa, music21, NumPy), 
not sampled or templated. This isn't 'AI-generated music' (no Jukebox, no MuseNet). 
It's a composer using self-written software to explore specific sonic ideas. 
AI was used to assist (Claude for code refactoring, lyrics), but all decisions are human-made."

**Ángulo 2 - Tema: Lies & Cognitive Dissonance**:
"The album examines mentiras (lies/cognitive dissonance) at four scales: 
political (Kicking Stones: systems that fail but we pretend work), 
personal (Rescue Us: impossible standards we know are irrational but maintain anyway), 
inherited (Medio Limón: traditions we think are eternal but are actually constructions), 
collective (Sin título: admitting we're all living these contradictions). 
Not a political statement from one side. Just: where's the boundary between belief and self-awareness?"

**Ángulo 3 - Estructura: Álbum como Canción**:
"The album reads as a single four-part song (verse → bridge → verse → chorus). 
Genre shifts (hip-hop → ambient → tropipop → indie-folk) serve structural roles, not stylistic variety for its own sake."

**Ángulo 4 - Vocal Delivery**:
"VOID CHILD's vocals are deliberately declamatory (parlato, not sung). 
Pitch analysis shows only 32% of vocal frames within ±20 cents of a defined pitch. 
This isn't technical limitation; it's expressive choice. For an album about lies and self-awareness, 
sung-to-perfection vocals would be ironic. The delivery is 'thinking aloud,' not 'performing.'"

## Cómo Explicar "Código + Composición" Sin Sonar Pretensioso

### ❌ Evitar:
- "Algorithmically generated" (suena robótico)
- "AI-created" (es falso y triggerea antifans)
- "Computer-produced" (insinúa falta de humanidad)
- "Synthesized" (es verdad, pero sonará menos interesante que la explicación real)

### ✅ Usar:
- "Custom code" (específico, no genérico)
- "Tool written for this album" (enfatiza intención)
- "Composed in Python" (honesto, técnico)
- "Each backing track has its own generator" (muestra pensamiento, no template-chasing)

### Frase Madre (repite esto):
"The backing track isn't produced—it's *composed*. Code was a tool to explore the exact sound this song needed."

## Talking Points Técnicos (Para Foros, Podcasts)

Si alguien pregunta detalles:

**P: ¿Cómo exactamente se genera un ritmo?**
R: "El compositor toma un patrón (ej. el ritmo vallenato real), lo analiza nota-por-nota con librosa, luego lo sintetiza con toques personalizados. No es 'presionar botón'; es traducir ritmo del mundo real a síntesis determinística."

**P: ¿Se puede reproducir el álbum idénticamente cada vez?**
R: "Los backing tracks sí (son determinísticos). La voz grabada, no. Eso es el punto: la máquina es consistente, la persona es interpretativa."

**P: ¿Por qué no grabar los instrumentos?**
R: "Porque la síntesis minimalista *es* la declaración estética. Si sonara como guitarra grabada, perderías el punto de que esto está pensado, no documentado."

**P: ¿Y si alguien quiere versionar este álbum?**
R: "La documentación es abierta. El código exacto (parcialmente), disponible. El punto es no gatekeep; es invitar a transformación."

## Red Flags & How to Avoid Them

### 🚩 Red Flag: "AI-created"
**Why**: Incorrect, triggery, oversimplifies
**Solution**: Use "code-composed" or "algorithmically structured" instead

### 🚩 Red Flag: Overpromising emotional impact
**Why**: Este álbum no hace llorar en escucha 1. Hace pensar.
**Solution**: Lead with "conceptually ambitious" not "emotionally devastating"

### 🚩 Red Flag: Burying the declamatory vocals
**Why**: Si alguien no está preparado y espera Adele, decepción
**Solution**: Be upfront: "Not traditionally sung; deliberately declamatory"

### 🚩 Red Flag: Making it sound harder to listen to than es
**Why**: "Algorithmically structured" suena como homework, no música
**Solution**: Always pair technical description with emotional/conceptual one
